Вход для администратора

Доступ только по паролю. Обычные страницы не показывают раздел «Админка» в меню. Пароль задаётся в js/admin-config.js — смените перед публикацией.

Сводка

Показатели по данным этого браузера (localStorage). Выберите период и блоки — цифры по заказам пересчитываются; каталог и рынок ниже — снимок «сейчас».

Ассортимент

Добавление и удаление сетов, цены, описания, картинка и ссылка на видео (YouTube или прямой mp4/webm).

Справочники тегов

      Фильтры боковой панели

      Коллекции (сундуки) и категории в блоке каталога на главной. ID — латиница, цифры и дефис (как в данных товаров: collectionId, category). Пункт с ID all нельзя удалить — это «все значения». В колонке «Родитель» у коллекции и у категории можно указать другую строку верхнего уровня — на витрине появится вложенный список; фильтр по родителю покажет товары с этим ID и с любых дочерних пунктов. Картинка: файл (лучше до ~300 KB) или ссылка https:// — на витрине слева тёмный фон плавно переходит в изображение справа.

      Заказы

      Список из локального кабинета этого браузера (те же заказы, что у клиента после оформления из корзины). У каждого заказа короткий номер и полный ID. «Подробнее» — состав, покупатель, Steam, история статусов. Справочник статусов задаётся в коде (js/account-store.js), позже можно заменить на настройки из админки.

      Активные и скрытые предложения по товарам. «Скрыть с витрины» убирает лот из стакана на карточке товара (покупатели не путаются). Данные хранятся локально в браузере, как и заказы.

      Тексты сайта

      Подмена абзаца и списка в блоке «Связь» на главной, подписи футера на всех страницах. Пустые поля — оставить текст по умолчанию из вёрстки.

      Пополнение Steam

      Цифры подставляются на страницу steam-topup.html. Нужен запуск сайта через сервер API (SKINEX_USE_SERVER_API).

      Дашборд пополнений

      Моментальное — запросы к партнёру (успех/ошибка). Ключи — переход в поддержку с расчётом (намерение оплатить, не факт оплаты).

      Выгодное пополнение (ключи TF2)

      На сайте показывается: сколько клиент заплатит (ключи × цена) и оценка «сколько получит на баланс Steam» = оплата × (1 + профит%).

      Подсказки

      Блок FAQ на странице «Поддержка»: заголовок пункта — вопрос в шапке раскрывающейся строки, текст — ответ под ним. Снятая галочка «На сайте» скрывает пункт. Число порядка: меньше — выше в списке.
